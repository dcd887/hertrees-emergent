# 规则之塔 · 涌现（HerTrees_MVP v3 涌现版）

黑白极简解谜 demo，单文件 HTML，浏览器直接打开即玩。

## 玩法

四个房间：灰度 → 数量 → 时间 → 涌现。

前三关是隐形的规则教学（灰度定生死、数量定排序、时序定重现），全靠关卡本身教会你，不写字幕。

第四关是元谜题：种子固定不动，只能拨动三条规则开关（灰度·生存 / 数量·诞生 / 时序·结算），同一个种子在不同规则下会长成不同的样子。三组谜题递进，每组在八种规则组合里只有唯一解——不是试出来的，是推出来的。
